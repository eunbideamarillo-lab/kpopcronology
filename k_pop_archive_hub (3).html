Guía: Cómo Subir a Internet Gratis

Dado que esta aplicación está empaquetada en un solo archivo index.html, publicarla en la web gratis toma solo un par de minutos:

  • 1
    Opción A: Netlify Drop (Más Fácil)
    Entra a app.netlify.com/drop. Arrastra y suelta la carpeta donde guardes este archivo index.html. Obtendrás un enlace público al instante.
  • 2
    Opción B: GitHub Pages
    Crea un repositorio público en GitHub, sube este archivo con el nombre index.html y activa GitHub Pages en las opciones del proyecto.
  • 3
    Opción C: Vercel
    Sube tu archivo a GitHub o usa la CLI de Vercel con el comando vercel deploy. Es instantáneo y totalmente gratuito.
